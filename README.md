# CodeMaster — C++ 학습 웹사이트

하루 다섯 문제로 C++ 기초부터 객체지향까지 학습하는 웹 프로그램입니다. 2주차에 개발한 HTML·CSS·JavaScript 웹 프로그램을 3주차에 GitHub Pages로 배포합니다.

**웹사이트:** https://gongrang1-pixel.github.io/CodeMaster-web/

**소스 저장소:** https://github.com/gongrang1-pixel/CodeMaster-web

## 주요 기능

- 초급·중급·고급 각 10개, 총 30개의 C++17 문제
- 선택한 난이도에서 중복 없이 무작위 5문제 출제
- 정답 제출 후 즉시 채점 및 해설 제공
- 퀴즈 결과, 오답 복습, 누적 XP와 레벨 표시
- 브라우저에 최근 20회 학습 기록 저장
- PC와 스마트폰 화면에 맞는 반응형 화면

## 사용 방법

1. 위 웹사이트 주소를 PC 또는 스마트폰 브라우저에서 엽니다. 설치나 로그인은 필요하지 않습니다.
2. **학습 시작하기** 또는 난이도별 **학습 시작** 버튼을 누릅니다.
3. 보기 하나를 선택하고 **정답 제출하기**를 누릅니다.
4. 해설을 읽고 **다음 문제**로 이동합니다.
5. 5문제를 마치면 **학습 결과 보기**에서 점수와 오답을 확인합니다.
6. **학습 기록** 메뉴에서 이전 결과를 다시 볼 수 있습니다.

정답당 20점·10XP이며 한 회 최대 100점·50XP입니다. 누적 XP가 100씩 증가할 때마다 레벨이 올라갑니다.

기록은 사용한 브라우저와 사이트 주소에 저장됩니다. 다른 기기와 자동 동기화되지 않으며 브라우저 데이터를 삭제하면 기록도 사라집니다. 진행 중인 퀴즈는 저장하지 않고 다섯 번째 답안을 제출하면 결과를 저장합니다.

## 프로젝트 구조

```text
CodeMaster-web/
├── docs/
│   ├── index.html          # 웹사이트 시작 화면
│   ├── style.css           # 반응형 스타일
│   ├── app.js              # 퀴즈·채점·학습 기록
│   └── data/questions.json # C++ 문제은행 30개
├── main.cpp
├── Question.h / Question.cpp
├── QuestionBank.h / QuestionBank.cpp
├── QuizGame.h / QuizGame.cpp
└── README.md
```

C++ 파일은 원본 콘솔 프로그램입니다. 공개 웹사이트는 `docs`의 정적 파일만 사용하며 외부 라이브러리, 유료 API, 백엔드 서버가 필요하지 않습니다.

## 로컬 실행

Python 3이 설치된 PC에서 프로젝트 폴더를 열고 실행합니다.

```bash
python -m http.server 8000 --directory docs
```

Windows에서는 `py -m http.server 8000 --directory docs`도 사용할 수 있습니다. 브라우저에서 http://localhost:8000 에 접속합니다. `index.html`을 더블 클릭하면 JSON 요청이 브라우저 보안 정책에 막힐 수 있으므로 HTTP 서버로 실행합니다.

## GitHub Pages 배포 설정

1. 저장소 **Settings → Pages**를 엽니다.
2. **Source: Deploy from a branch**를 선택합니다.
3. **Branch: main**, **Folder: /docs**를 선택하고 **Save**합니다.
4. 배포가 완료되면 위 웹사이트 주소로 접속합니다.

이후 `main` 브랜치의 `docs` 파일을 수정하면 Pages가 다시 배포합니다. 파일 경로는 프로젝트 저장소의 하위 주소에서도 작동하는 상대경로입니다.

## 스마트폰 확인 항목

- 주소를 열었을 때 대시보드가 표시되는지 확인합니다.
- 초급·중급·고급 학습 시작 버튼과 보기 선택을 터치합니다.
- 5문제 풀이 후 점수·해설·오답을 확인합니다.
- 학습 기록을 열고 새로고침 후에도 결과가 유지되는지 확인합니다.
- 세로·가로 화면에서 글자와 버튼이 잘리지 않는지 확인합니다.

실제 스마트폰 기기에서의 확인은 사용자가 위 항목을 직접 테스트해야 합니다.
